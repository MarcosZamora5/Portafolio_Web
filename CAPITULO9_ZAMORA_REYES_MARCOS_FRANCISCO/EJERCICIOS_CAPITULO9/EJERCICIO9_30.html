9.30 ¿Qué hace la siguiente función?

function misterio( a, b )
{
   if ( b == 1)
      return a;
   else
      return a + misterio(a, b - 1);
}

Respuesta: La función calcula el producto de la multiplicación de dos números enteros a y b mediante sumas recursivas sucesivas (esencialmente simula la operación a * b utilizando únicamente sumas). Por ejemplo, si se llama misterio(4, 3), realiza la suma 4 + 4 + 4, devolviendo como resultado 12.
