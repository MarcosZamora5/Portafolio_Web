9.5 Localice el error en cada uno de los siguientes segmentos de programa y explique cómo corregirlo:

  1. method g()
{
   document.writeln( "Dentro del m&eacute;todo g" );
}
    Error: method no es la palabra clave que se utiliza para comenzar la definición de una función.
    Corrección: Cambiar method a function. 
    function g()
{
   document.writeln( "Dentro de la función g" );
}
  2. // Esta función debe devolver la suma de sus argumentos
function suma(x, y)
{
   var resultado;
   resultado = x + y;
}
    Error: Se supone que la función debe devolver un valor, pero no es así.
    Corrección: Eliminar la variable resultado y colocar la instrucción return x + y; en la función, o agregar la instrucción return resultado; al final del cuerpo de la función: 
    function suma(x, y)
{
   var resultado;
   resultado = x + y;
   return resultado;
}
  3. function f( a );
{
   document.writeln( a );
}
    Error: El punto y coma después del paréntesis derecho que encierra la lista de parámetros.
    Corrección: Elimine el punto y coma después del paréntesis derecho de la lista de parámetros: 
    function f( a )
{
   document.writeln( a );
}
