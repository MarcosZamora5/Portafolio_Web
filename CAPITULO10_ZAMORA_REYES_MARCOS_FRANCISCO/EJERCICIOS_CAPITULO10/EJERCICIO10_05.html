Ejercicio 10.5 - Encuentre el o los errores y corríjalos:

  1. var b = new Array( 10 );
var longitud = b.length;

for ( var i = 0; i <= longitud; ++i )
{
   b[ i ] = 1;
}

    Error: Se hace referencia al elemento de un arreglo fuera de los límites del arreglo (b[10]) [Nota: en realidad éste es un error lógico y no sintáctico].
    Corrección: Cambie el operador <= a < en la condición del ciclo for ( var i = 0; i < longitud; ++i ).

  2. var a = [ [ 1, 2 ], [ 3, 4 ] ];
a[ 1, 1 ] = 5;

    Error: El indexado de arreglos bidimensionales se realiza de manera incorrecta usando coma dentro de un mismo corchete.
    Corrección: Cambie la instrucción a a[ 1 ][ 1 ] = 5;.
