7.9 Identifique y corrija los errores en cada uno de los siguientes segmentos de código.

  1. if ( edad >= 65 );
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65 )";
    Errores: 1) El punto y coma (;) al final de if ( edad >= 65 ); termina prematuramente la instrucción if, dejando el else sin un if asociado (error de sintaxis).
    2) En el segundo document.writeln, las comillas de cierre están colocadas después del paréntesis de cierre en lugar de antes.
    Corrección: 
    if ( edad >= 65 )
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65" );
  2. var x = 1, total;
while ( x <= 10 )
{
   total += x;
   ++x;
}
    Error: La variable total no fue inicializada antes de usarse en el cálculo, por lo que su valor inicial es undefined y el resultado será NaN.
    Corrección: Inicializar total = 0. 
    var x = 1, total = 0;
while ( x <= 10 )
{
   total += x;
   ++x;
}
  3. var x = 1;
var total = 0;
while ( x <= 100 )
   total += x;
   ++x;
    Error: Faltan las llaves { } que delimitan el cuerpo del ciclo while. Sin ellas, sólo total += x; forma parte del ciclo y ++x; nunca se ejecuta dentro de él, provocando un ciclo infinito.
    Corrección: 
    var x = 1;
var total = 0;
while ( x <= 100 )
{
   total += x;
   ++x;
}
  4. var y = 5;
while ( y > 0 )
{
   document.writeln( y );
   ++y;
}
    Error: Incrementar y (++y;) cuando empieza en 5 y la condición es y > 0 provoca un ciclo infinito, ya que y siempre será mayor que 0.
    Corrección: Cambiar ++y; por --y; para decrementar la variable hasta que llegue a 0. 
    var y = 5;
while ( y > 0 )
{
   document.writeln( y );
   --y;
}
