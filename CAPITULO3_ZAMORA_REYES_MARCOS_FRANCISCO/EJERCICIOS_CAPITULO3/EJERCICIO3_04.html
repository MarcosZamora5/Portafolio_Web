Ejercicio 3.4 - Verdadero o falso

a) Falso. Cuando el navegador despliega el input color como campo de texto, requiere que el usuario introduzca un codigo hexadecimal, no el nombre del color.

b) Falso. El navegador verifica si los datos son correctos de inmediato antes de enviarlos al servidor.

c) Falso. HTML5 solo valida que la direccion tenga el formato de un correo electronico, pero no comprueba si el correo existe realmente.

d) Verdadero. Se puede agregar el atributo required a cualquiera de los tipos input.

e) Verdadero. Puedes habilitar la opcion de autocomplete solo para ciertos elementos especificos del input.

f) Verdadero. El elemento time nos permite identificar una fecha, hora o ambas.

g) Falso. El elemento que proporciona una leyenda para la imagen es figcaption, no caption.

h) Falso. Aunque la flecha la maneja details, el texto que apunta a la derecha y sirve de leyenda se define especificamente con la etiqueta summary.

i) Verdadero. El elemento footer describe el contenido en la parte inferior del documento o section.

j) Falso. El elemento correcto para resaltar texto en HTML5 es mark, no highlight.
