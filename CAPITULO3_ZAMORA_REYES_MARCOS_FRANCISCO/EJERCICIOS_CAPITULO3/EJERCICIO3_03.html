Ejercicio 3.3 - Completar las oraciones

a) El atributo autofocus (que se utiliza en un solo elemento input en un formulario) resalta de manera automatica el elemento input y coloca el cursor en el campo de texto despues de que el navegador carga.

b) Los nuevos tipos input de HTML5 tienen validacion automatica del lado del cliente.

c) El tipo input number permite al usuario introducir un valor numerico.

d) El tipo input range se valida automaticamente de manera intrinseca cuando lo despliega el navegador como un control deslizante.

e) El atributo autocomplete puede usarse en los tipos input para completar de manera automatica la informacion del usuario.

f) El elemento figcaption proporciona una leyenda para la imagen en el elemento figure.

g) El elemento summary muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Revela el contenido del elemento details.

h) El elemento mark nos permite resaltar texto.
