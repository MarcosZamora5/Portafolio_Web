Ejercicio 3.1 - Completar las oraciones

a) El tipo input color permite al usuario introducir un color. Al momento de escribir este libro, la mayoria de los navegadores despliegan el tipo input color como un campo de texto en donde el usuario puede introducir un codigo hexadecimal.

b) El atributo placeholder nos permite colocar texto temporal en un campo de texto.

c) Si desea anular la validacion, puede agregar el atributo formnovalidate al tipo input submit.

d) El atributo required obliga al usuario a introducir un valor antes de enviar el formulario.

e) Por lo general se muestra el control spinner para el tipo input number e incluye solo los numeros validos.

f) El tipo input time permite al usuario introducir una hora, minuto, segundo y fraccion de segundo.

g) El elemento datalist proporciona opciones de entrada para un elemento input text.

h) El elemento article describe contenido que esta separado del contenido principal de la pagina y que posiblemente podria utilizarse o distribuirse en otra parte.

i) El elemento footer describe el texto que por lo general aparece en la parte inferior del contenido o de un elemento section.

j) El elemento wbr indica el lugar apropiado para dividir una palabra cuando el texto se ajusta en varias lineas.
