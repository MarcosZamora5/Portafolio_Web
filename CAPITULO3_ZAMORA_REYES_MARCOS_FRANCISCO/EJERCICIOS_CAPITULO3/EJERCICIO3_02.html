Ejercicio 3.2 - Verdadero o falso

a) Falso. El despliegue de los tipos input de HTML5 puede variar dependiendo del navegador que se este utilizando.

b) Falso. Cuando se coloca el enfoque en el campo de texto, el texto del atributo placeholder desaparece de la pantalla, no se envia al servidor.

c) Verdadero. No es estrictamente necesario incluir el atributo autofocus en los formularios.

d) Verdadero. La validacion automatica elimina la necesidad de agregar secuencias de comandos complicadas.

e) Verdadero. El tipo input range se valida automaticamente de manera intrinseca.

f) Falso. HTML5 no cuenta con validacion automatica para el tipo input tel debido a los multiples formatos de numeros telefonicos en el mundo.

g) Verdadero. HTML5 revisa que el formato del URL sea el adecuado, pero no puede verificar si la pagina web realmente existe en internet.

h) Falso. El elemento nav solo agrupa vinculos de navegacion, no crea un menu desplegable por si mismo sin ayuda extra.

i) Falso. El elemento header puede utilizarse multiples veces dentro de una misma pagina.

j) Verdadero. Los elementos nav si pueden estar anidados dentro de un elemento aside.

k) Falso. Para evitar dividir palabras en lugares incorrectos se utiliza el elemento wbr, no brk.
