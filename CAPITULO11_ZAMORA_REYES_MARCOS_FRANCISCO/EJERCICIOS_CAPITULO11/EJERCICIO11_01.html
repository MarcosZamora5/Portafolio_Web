Ejercicio 11.1 - Respuestas de Autoevaluación

  1. Lenguaje de programación basado en objetos: lenguaje de programación basado en objetos.
  2. Propiedades de los objetos: atributos y comportamientos.
  3. Objeto para cálculos matemáticos comunes: Math.
  4. Proceso de invocar el método de un objeto: enviar un mensaje al objeto.
  5. Delimitadores para literales de cadena: comillas dobles o comillas sencillas.
  6. Índice inicial para los caracteres de una cadena: 0.
  7. Métodos de String para buscar la primera y última ocurrencia: indexOf y lastIndexOf.
  8. Proceso de dividir una cadena en partes individuales: tokenización.
  9. Referencias para el procesamiento de fechas y horas: zona horaria local de la computadora o Tiempo Universal Coordinado (UTC).
  10. Método de Date que convierte una cadena de fecha a milisegundos desde 1970: parse.
  11. Propiedad de window para guardar pares clave/valor de forma persistente entre sesiones: localStorage.
  12. Propiedad de window para guardar datos únicamente durante una sesión y pestaña activa: sessionStorage.
  13. Selector de CSS3 para el primer elemento hijo: :first-child.
  14. Selector de CSS3 para elementos hijos pares (even) o impares (odd): :nth-child.
